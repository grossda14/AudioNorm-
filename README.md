# AudioNorm+

[![CI](https://github.com/grossda14/AudioNorm-/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/grossda14/AudioNorm-/actions/workflows/ci.yml)
[![CodeQL](https://github.com/grossda14/AudioNorm-/actions/workflows/codeql.yml/badge.svg?branch=main)](https://github.com/grossda14/AudioNorm-/actions/workflows/codeql.yml)

AudioNorm+ is a Windows-focused .NET 8 desktop app for analyzing audio loudness and writing ReplayGain metadata.

## Automation

- **CI**: restores, builds, and validates tests on pull requests and pushes to `main`/`develop`
- **CodeQL**: runs GitHub's C# security analysis and uploads results to the Security tab
- **Release**: publishes a self-contained Windows x64 executable for tags and manual releases
