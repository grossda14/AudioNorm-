# CHANGELOG.md
All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-25

### Added
- Initial release of AudioNorm+
- Windows Forms GUI application
- Support for MP3 files with ID3v2 tag writing
- Support for AAC/M4A files with iTunes atom tag writing
- Track-based analysis mode for individual file processing
- Album-based analysis mode for collective track processing
- Replay gain calculation based on EBU R128 loudness standards
- Gain adjustment slider with 0.5dB increments (-24dB to +24dB)
- Automatic backup creation before applying gain (.bak files)
- Audio loudness analysis and measurement in LUFS
- Batch file processing support
- DataGridView display with file metadata and status tracking
- Professional Windows Forms UI with intuitive controls
- Duration display for loaded audio files
- Real-time gain value preview
- ReplayGain metadata tag writing (REPLAYGAIN_TRACK_GAIN, REPLAYGAIN_ALBUM_GAIN)
- Comprehensive documentation and usage guide
- Build scripts for Windows (batch and PowerShell)
- Build scripts for Linux/macOS (Bash)
- Contributing guidelines
